forecast

time-resolved, multi-source observational field generator

An ingestion and validation engine that pulls heterogeneous real-world data streams, preserves atomic observations, and maintains temporal and spatial fidelity for downstream latent variable construction.

Active sources: METAR (aviation weather), AirNow (air quality). Planned: NEXRAD, NLDN, HRRR Smoke, FIRMS, NOTAM, transport, news.

The public HTTP surface is not live yet — this domain currently serves as the canonical landing for the project. See the repo for status and roadmap.
